Powering Real-Time Bluetooth Tracking in Laravel with the NativePHP BLE Plugin

By Sonali Dudhia • Apr 29, 2026 • 11 min read

NativePHP Laravel BLE Livewire

Bluetooth Low Energy (BLE) powers everything from smart bands to wireless thermometers, but until now, accessing it from Laravel felt impossible. Thanks to the BLE Tracking Plugin for NativePHP Mobile, you can now scan, connect, and track Bluetooth devices right from your PHP and Livewire code, with no Swift or Kotlin required.

Why BLE Tracking in NativePHP?

If you have ever tried talking to BLE hardware from a hybrid or web-based stack, you know the pain. Native APIs differ between iOS and Android, and handling asynchronous events or device reconnections can get messy quickly.

NativePHP's plugin system makes native integration approachable for PHP developers. With this BLE plugin, sonali/ble-tracking, you can:

  • Continuously scan for nearby BLE devices.
  • Connect and disconnect from devices programmatically.
  • Track signal strength (RSSI) in real time.
  • Receive Livewire events when devices appear, connect, or disconnect.
  • Handle iOS-specific system peripherals like Apple Watch or devices paired through Zepp.

All of it uses familiar Laravel syntax within the same ecosystem as your backend.

Getting Started

You need PHP 8.1+ and NativePHP Mobile 3.0+ (with Android 5.0+ or iOS 13+).

Install via Composer

Add the repository to your composer.json:

{
  "repositories": [
    {
      "type": "path",
      "url": "../ble-tracking-plugin"
    }
  ]
}

Then install:

composer require sonalidudhia/nativephp-ble-tracking

Register the Plugin

Add the service provider to your NativeServiceProvider:

public function plugins(): array
{
    return [
        \NativePHP\BLETracking\BLETrackingServiceProvider::class,
    ];
}

Now rebuild for iOS or Android:

php artisan native:run android
# or
php artisan native:run ios

And you are live.

Scanning for Devices

The plugin provides a clean API through the BLETracking facade: 

use NativePHP\BLETracking\Facades\BLETracking;

$scan = BLETracking::startScanning();

if ($scan['success']) {
    // Listen for DeviceDiscovered events
}

Stop scanning with:

BLETracking::stopScanning();

During scanning, nearby BLE devices trigger events you can catch directly in Livewire.

Handling Live Events in Laravel

Each plugin action fires native events under the hood. In Livewire, you can subscribe using the OnNative attribute: 

use Native\Mobile\Attributes\OnNative;
use NativePHP\BLETracking\Events\DeviceDiscovered;

#[OnNative(DeviceDiscovered::class)]
public function handleDiscovered(string $deviceId, string $deviceName, int $rssi)
{
    $proximity = $rssi >= -60 ? 'Very Close' : ($rssi >= -75 ? 'Nearby' : 'Far');
    // Update your dashboard UI
}

Other available events:

  • DeviceConnected
  • DeviceDisconnected
  • ConnectionFailed
  • ScanningStarted
  • ScanningStopped

RSSI and Proximity Detection

RSSI (signal strength) gives you an approximate sense of how close a device is.

RSSI Range Proximity
>= -60 dBm Very Close
-61 to -75 dBm Nearby
< -75 dBm Far

Example: Building a BLE Dashboard in Livewire

Below is a simplified version of the included Livewire component (BleDashboard):

class BleDashboard extends Component
{
    public array $devices = [];
    public bool $scanning = false;

    public function startScanning()
    {
        $this->scanning = BLETracking::startScanning()['success'];
    }

    #[OnNative(DeviceDiscovered::class)]
    public function addDevice(string $deviceId, string $deviceName, int $rssi)
    {
        $this->devices[$deviceId] = [
            'name' => $deviceName,
            'rssi' => $rssi,
            'proximity' => $this->getProximity($rssi),
        ];
    }

    private function getProximity(int $rssi): string
    {
        return $rssi >= -60 ? 'Very Close' : ($rssi >= -75 ? 'Nearby' : 'Far');
    }
}

Rendered through Blade with wire:poll updates, you get a responsive BLE scanner UI written entirely in PHP.

iOS vs Android Behavior

Capability iOS Android
Real-time scanning Yes Yes
reconnectKnownDevices Yes No (not supported)
scanSystemPeripherals Yes No
Manufacturer detection (Apple ID 0x004C) Yes No
Async connection flow Waits for result Initiates connection and returns immediately

The iOS side uses CoreBluetooth (CBCentralManager and related APIs), while Android uses RxAndroidBle for non-blocking BLE streams.

Permissions Overview

NativePHP handles permission prompts for you. Here is what gets requested.

Android:

  • BLUETOOTH, BLUETOOTHADMIN
  • BLUETOOTHSCAN, BLUETOOTHCONNECT (Android 12+)
  • ACCESSFINE_LOCATION

iOS:

  • NSBluetoothAlwaysUsageDescription
  • NSBluetoothPeripheralUsageDescription

To scan in the background, enable bluetooth-central mode in Xcode project settings.

Under the Hood

  • Android: RxAndroidBle v1.17.2 and RxJava 3.1.8
  • iOS: Built on Apple's CoreBluetooth framework
  • License: MIT

The plugin uses the same architecture as official NativePHP packages, combining Kotlin and Swift layers with a PHP facade and event bridge.
